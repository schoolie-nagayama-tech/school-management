# 講師の家モード（教室端末マーク + スコープ分割）設計

作成: 2026-08-18 / 状態: 実装中（このworktree）

## 0. 目的と脅威モデル

- 講師に「家からシフト・出勤簿の確認」を許しつつ、「家から生徒情報を閲覧する」日常を作らない。
- IP制限は不可（教室に固定IPの錨が無い。docs外の過去検討で先送り済み）。代わりに**教室端末マーク**を錨にする。
- これは**ソフト境界**である。悪意ある持ち出し（教室での画面撮影・クッキー複製・PostgREST直叩き）は防げない。目的は (1) 日常的に家で生徒情報を開かない構造化 (2) 端末紛失・家族の覗き見という事故の低減 (3) 規程運用の土台。RLSによる既存の防御（教室スコープ等）は一切変えない。

## 1. 確定した設計判断（2026-08-18 ユーザー確定）

1. **入口は1つのまま**（LINE二入口案は不採用）。通常ログインの後、端末マークの有無で「教室モード（フル）/ 家モード（制限）」が自動で決まる。
2. **端末マークは端末（ブラウザプロファイル）に紐づき、ログインする人が変わっても有効**。室長/adminが教室の共有PCで一度発行する。
3. **対象ロールは teacher のみ**。manager 以上は家でもフル（管理責任側のため）。
4. **家OKセット**: 本日の授業(/today)・自分の予定(/my-schedule)・自分の出勤簿・シフト提出/確認・研修バッジ・連絡掲示板・アカウント設定・ヘルプ。
5. **教室限定セット**: 生徒管理・進行表・報告書の記入閲覧・成績・座席表・回答一覧・テスト対策・申込状況。
6. **⚠️ 未確定（社内で最終判断）**: /today・/my-schedule の**生徒名表示**。現段階は「出す」で実装するが、表示は必ず共通ヘルパー（displayStudentNameForTeacher 等）を通し、マスク（例:「中2英語」だけ）への切替が1箇所で済む構造にする。
7. 講師のログイン後の着地を /students → **/today** に変更し、講師ナビに「本日の授業」「自分の予定」を追加する（従来の隠し公開を正式導線に）。

## 2. 仕組み

### 端末マーク
- テーブル `trusted_devices`: id / school_id / label / token_hash / created_by / created_at / last_seen_at / revoked_at。
- 発行: `/settings/trusted-devices`（manager以上）で「この端末を登録」→ サーバーがランダムトークン発行、**hashのみDB保存**、ブラウザへ httpOnly + Secure + SameSite=Lax の長期クッキー（2年）を設定。
- 失効: 同ページの一覧から revoke（revoked_at セット）。紛失端末対策。
- 判定: サーバーがクッキーのトークンを hash 照合し、未失効なら信頼済み。**クッキーは httpOnly なのでJSからは読めない**。判定結果だけを `/api/device-trust/status` が返す。
- アクセス権: trusted_devices は service role 専用（anon/authenticated には一切 GRANT しない。既定権限の罠に注意）。

### 家モードの強制
- 判定式: `role=teacher かつ 信頼済み端末でない` → 家モード。
- **ページゲート**: RootLayout に HomeModeGate（既存 UnreadBulletinGate と同型）。教室限定パス（前方一致リストを1ファイルに集約）に家モードで入ったら全画面ブロック「この機能は教室の端末でのみ利用できます」＋家OKページへの導線。
- **ナビ**: navConfig / MobileBottomNav に homeMode を渡し、教室限定の項目は非表示（死にリンクを見せない）。
- **API**: 既存の管理系APIルートは家モード講師を 403（getApiAuth 系に判定を追加）。
- **限界の明記**: 講師の生徒データ読取は RLS 前提のクライアント直読が主経路のため、セッショントークンを使った PostgREST 直叩きはページゲートでは塞げない。これは §0 の脅威モデルどおり許容する（ソフト境界）。

## 3. 運用

- 初期セットアップ: 各教室の共有PC（ブラウザごと・PWA別）で室長が発行。
- マークが消えるケース: 閲覧データ削除 / シークレット / 別ブラウザ → 室長が再発行。
- 講師への説明: 「教室のPCでは今まで通り。家からは自分のシフト・出勤簿だけ見える」。
