# AIヘルプで学校名を答える（高校マスタの引き当て）

AIヘルプ（`/api/ai/help`）が、FAQ本文に加えて**高校マスタ**を材料に使う仕組み。
「日比谷の偏差値は？」「内申100くらいの神奈川の高校は？」に答えるためのもの。

正典の親: [ai-help-plan.md](ai-help-plan.md) ／ データの出どころ: [data/README.md](data/README.md)

---

## なぜFAQ本文に書かなかったか

学校ごとの数字（404校×学科）を `faqData.ts` に書く案を捨てた。理由は3つ。

1. **見出しカタログが膨らむ。** 1回目の呼び出しは全項目の見出しを毎回渡している。
   そこに400校ぶんの行が増えると、キャッシュしている塊が別物になる。
2. **数字がソースコードに凍る。** めやすは毎年変わる。差し替えのたびにPRになり、
   本番に出すまで古い数字が答え続ける。
3. **版管理が二重になる。** `high_school_standards` は `source_year` で版を積み、
   `verified_at` で「人間が紙を見たか」を持っている。FAQに書き写すと、この2つが死ぬ。

マスタは既に版と出典を持っている。そこを読むほうが正しい。

## 作り

材料が2つあり、**選び方が違う**。

| 材料       | 選び方                                  | どこ                         |
| ---------- | --------------------------------------- | ---------------------------- |
| FAQ本文    | 2段階。見出しの一覧をAIに見せて選ばせる | `src/lib/help/faqIndex.ts`   |
| 高校マスタ | **質問文から直接引く。AIに選ばせない**  | `src/lib/ai/schoolLookup.ts` |

学校をAIに選ばせないのは、選ばせる必要が無いから。学校名は質問文にそのまま出るので、
文字列で当たる。1回分の呼び出しを節約できるうえ、AIが存在しない学校を選ぶ余地も無くなる。

```
質問
 ├─ 1回目（AI）: FAQの見出し一覧 → 最大3項目
 ├─ 引き当て（コード）: 質問文 → 高校マスタの行（最大24行）
 └─ 2回目（AI）: FAQ本文 ＋ 用語集 ＋【学校のめやす】 → 答え
```

★**FAQが0件でも、学校が当たっていれば回答へ進む。**
「日比谷の偏差値は？」に当たるFAQ項目は無いため、ここを直さないと黙ってしまう。

- `src/lib/ai/schoolLookup.ts` … 純関数（引き当てと本文の組み立て）。テストはここを直接触る
- `src/lib/ai/schoolMaster.ts` … server-only。DBを読んでキャッシュする
- `src/lib/help/aiHelpPrompts.ts` … 「渡した行の数字だけを読む」の縛り

## 引き当ての決まり

### 学校名

質問文に学校名が**部分文字列として出るか**で当てる（日本語は分かち書きしないので、
`keywordSearch` の2段目と同じ考え方）。

- **長い名前を先に当てる。** 「市立横浜総合」に当たったら「横浜」では拾わない
- **`市立`／`県立`／`都立` を外した別名でも当てる。** 「横浜サイエンスフロンティア」で
  `市立横浜サイエンスフロンティア` に当たる
- ★**1文字の学校名は文脈を要求する。** 西・東・菅・旭・橘 は実在するが、
  そのまま当てると「**東**京の私立は」「関**西**の…」で誤爆する。
  `◯◯高` `都立◯◯` `県立◯◯` `市立◯◯` の形のときだけ当てる
- ★**2文字の学校名には文脈を求めない。** 戸山・湘南・三田・上野・北園・鎌倉・上溝など、
  いちばん聞かれる学校の多くが2文字で、「戸山の偏差値」と書くのが普通だから。
  最初は2文字にも文脈を求めていて、テストで「上溝の内申」が当たらないことに気づいた。
  地名と同じ名前（厚木・鎌倉など）に当たっても、渡るのはその学校の行だけで、
  答えるかどうかはプロンプト側が質問に照らして決めるので害は小さい
- **例外は「国立」。** 「国立大学」の国立に当てないよう、直後に「大」が続くときは外す

### 範囲

「偏差値55」「内申100」を正規表現で拾い、**±2**の帯で引く。

★**満点の違う内申を混ぜない。** 質問の数字が65以下なら65/75/52点満点の行（東京）、
66以上なら135点満点の行（神奈川）だけを見る。
「内申55」で神奈川の55（135点満点＝かなり低い）を混ぜると事故る。

### 場所（市区町村・駅・沿線）— 東京だけ（都立・私立・国立）

「八王子にある都立は？」「清瀬駅から近くて偏差値50の高校は？」「中央線沿いで偏差値60くらい」に答える。
2026-09-28 から東京の私立・国立も対象（所在地・駅のデータがある学校だけ当たる。東京の私立は418行中397行にある）。
★**神奈川は対象外。** 所在地のデータは後から入った（公立199/199・私立110/139）が、市区町村が
「横浜市港北区」「相模原市中央区」の形で、東京の「北区」「中央区」と呼び名がぶつかる。
読み分けを作るまで場所では引かない。神奈川を場所で聞かれたら、行を渡さずに
「場所ではまだ探せない」と伝える本文だけを渡す（黙らせない）。

★**拾う順番に意味がある。** 当たった語を伏せ字にしてから次の種類を探す。

| 順  | 種類                              | 例と、なぜこの順か                                                                                 |
| --- | --------------------------------- | -------------------------------------------------------------------------------------------------- |
| 1   | 路線                              | 「日比谷線」を先に取る。後で学校の日比谷に当てないため                                             |
| 2   | 駅（`駅` `から近` `周辺` が続く） | 「清瀬駅」を先に取る。学校の清瀬に当てないため。「から」単独は入れない（「日比谷から西に変える」） |
| 3   | 市区町村の正式名                  | 「八王子市」「北区」                                                                               |
| 4   | 市区町村の略称＋`にある` など     | 「町田にある」。学校の町田より先に取る                                                             |
| 5   | 学校名                            | 従来どおり                                                                                         |
| 6   | 残りの市区町村の略称              | 学校名と同じ呼び方（府中・町田・国立）と、直後が「大」（中央大学）は除く                           |

- **市区町村の略称は2文字以上。** 北区→「北」を当てると「八王子北にある」で北区に取られる
- **学校名が当たったら学校名で答える。** 場所は探さない（駅が出ていれば距離だけ添える）
- 種類が違う条件は「かつ」、同じ種類は「または」
- 路線は `lineAliases` がふだんの呼び名を作る（`東京地下鉄 5号線東西線`→`東西線`・`東京メトロ東西線`）。
  ★「本線」だけは会社名なしで当てない（京成本線と京急本線）
- **会社名の呼び方（「西武線」「小田急線」「都営線」）はその会社の全路線に当てる。**
  ただし「京王線」のように特定の路線の呼び名でもあるものは、その路線だけ（井の頭線まで並べない）。
  2026-09-23、本番で「西武線沿線 都立」が引けなかったのがきっかけ
- ★**同じ呼び名が複数の路線を指すときは全部当てる**（「新宿線」＝西武新宿線と都営新宿線）。
  最初は1件目で伏せ字にしてしまい、2件目が落ちていた
- 学校が引けなかったときは「その聞き方では引けなかった」と言い換え例を出させる（FAQの rules）。
  同じ質問をそのまま勧め返したことがある

#### ふだんの言い方を読み取る（2026-09-23）

人は正式名称で聞かない。本番の質問ログ（`help_questions`）に実際に来た聞き方をもとに足した。
★**聞き方を直させない。** 「清瀬にある高校で都立で調べて」のように、言わなくても分かる言葉を
足すよう案内していたのをやめた（場所で探せるのは都立だけなので、都立と言わなくても都立を探している）。

| 聞き方                                       | 読み方                                                               |
| -------------------------------------------- | -------------------------------------------------------------------- |
| 「内申が35くらい」「偏差値は５０」           | 助詞をはさんだ数字・全角数字も拾う（`normalizeText`・`parseRange`）  |
| 「八王子で」「町田で偏差値50」「清瀬の高校」 | 地名＋「で」「の高校」「にある」は場所。「町田の偏差値」は学校       |
| 「清瀬近くの高校」                           | 駅（「近く」「の近く」「周辺」も駅の合図）                           |
| 「西武線」「西武沿線」「小田急沿い」         | その会社の全路線。「京王線」は京王線だけ                             |
| 「京浜東北線」「埼京線」「丸の内線」「TX」   | 線路名への読み替え（`LINE_NICKNAMES`）                               |
| 「23区」「多摩地区」「都下」                 | 市区町村のまとまり。多摩は島しょ部を外す                             |
| 「翠嵐」「サイフロ」                         | 地名の冠を外した略称・あだ名（一般語になる工業・国際などは作らない） |
| 「ひばりが丘」「緑ケ丘」                     | ヶ・ケ・が の書き分けをそろえる                                      |

★**学校が多いときは一覧を `steps` に1校1行で出させ、出力上限も上げた（900→2000）。**
「京王線沿線　都立」で24校を answer に書かせたら出力が上限で切れ、JSONが壊れて
「答えられない」になっていた。

#### 駅から近い

「駅から近い」＝ **直線2km圏の学校**（`access_stations` にその駅がある）＋ **同じ沿線で直線およそ8km以内の学校**。

- ★8kmの上限が無いと、「清瀬駅から近い」に西武池袋線の反対側の中野区の学校まで並ぶ
- 駅→路線・駅の座標の表は持っていないので、マスタから代える
  - 路線: その駅を主たる最寄駅にしている学校の `primary_lines`。無ければ、その駅を2km圏に持つ
    2校以上の `access_lines` の共通部分（access_lines は通える駅の全路線なので、駅の路線は必ず含まれる）
  - 位置: その駅がいちばん近い学校の座標。沿線の学校の距離は「およそ」と書かせる
- 並びは駅に近い順。範囲（偏差値・内申）を付けたときは帯で絞り、帯に1校も無ければ
  値の近い順に5行だけ渡して「帯には無い」と条件に書く（場所で絞ると帯が空になりやすい）
- ★距離は直線。「最寄駅」「徒歩◯分」「通いやすい」とは言わせない（docs/data/README.md の最寄駅の罠）

データは `high_schools.access_stations`（`駅名(距離m)` の text[]）。2026-09-23 に追加し、
`toritsu-school-station-r7.csv` から本番へ流し込んだ（203/205行。産業技術高専・大島海洋国際は駅データなし）。

### 県の絞り込み

質問に `都立` `東京` があれば東京都、`神奈川` `県立` `横浜` `川崎` などがあれば神奈川県。
私立を入れてからは `埼玉` `千葉` `茨城` `栃木` `山梨` も読む。
2つ以上・どれも無ければ絞らない（並べて出す）。

★**学校名で引いたときは、学校名を伏せた質問から県を読む。** 「東京農大三」（埼玉の私立）の
「東京」で東京都に絞ると、その学校自身が落ちる。「都立西」の「都立」は名前ではないので残す。

### 設置区分の絞り込み（2026-09-28）

`私立` `私学` があれば私立、`都立` `県立` `市立` `公立` があれば公立。
★**「国立」だけでは国立とみなさない。** 都立国立高校と国立市があるので、
`国立大附属` `国公立` `国立校` `国立・私立` のように区分と分かる形のときだけ。
何も言わなければ絞らない（公立・私立・国立をまとめて出す）。

## 私立・国立（2026-09-28）

PR #251 で `high_schools` に私立（833行）・国立（18行）が入った。それまでAIヘルプは
`establishment='公立'` で読み込みを絞っていた（「駅から近い都立」に私立が混ざると、私立を都立として
案内してしまうため）。区分・コース・男女別偏差値・基準の読み方を足したので絞り込みを外した。

| 違い                   | 扱い                                                                                                                  |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 同じ学校でコースが複数 | 行＝学校×コース。名前で引くと全コースが出る（上限24行。超えたら「先頭の24行だけ」と条件に書く）                       |
| 偏差値が男女別         | `high_school_standards.gender`。男女で違えば `hensachi=null` にして両方を渡す（`summarizeHensachi`）。★片方に寄せない |
| 内申のめやすが無い     | 代わりに推薦・併願優遇の基準（`high_school_admission_rules` の最新年度）を文にして渡す（`toAdmissionText`）           |
| 受けられない区分       | ★「都神外生」など、東京・神奈川の生徒が受けられない区分は渡さない（`scopeApplies` で両都県とも外れるもの）            |
| 国立                   | めやすの行が無い。偏差値は「資料なし」と書き、推薦の基準だけ渡す                                                      |

- 基準の文は `privateAdmission.ts` の読み（`ruleHeading` / `ruleCriterionText` / `ruleConditionChips`）を
  そのまま使う。面談ワークスペースの表と同じ言葉になる
- ★**判定はしない。** 基準（「併願（公私）: 内申 5科22」）を示すだけで、生徒の内申に当てない。
  AIヘルプは生徒の情報を送らない唯一のAI機能で、この性質を崩さない。判定は面談ワークスペースの志望校で見る
- 1〜3校を名前で引いたときは、加点の中身と確認事項（欠席日数・面接など）まで渡す。
  一覧（場所・範囲）のときは「加点あり」だけにして、プロンプトを膨らませない
- ★**県・市と同じ名前の私立は文脈を要求する。** 私立に「東京」「横浜」という学校があり、そのまま当てると
  「東京の私立の入試相談は？」で東京高校の行だけが渡る。1文字の学校名と同じく、`東京高` `私立横浜` の形のときだけ当てる。
  「向上」「大成」「中村」「正則」「城北」「東洋」もふつうの言葉なので同じ扱い（`GENERIC_PRIVATE_NAMES`）
- ★**私立は内申の数字で探せない。** 基準が学校・区分ごとに5科・9科・3科と形が違い、同じ「内申30」で比べられない。
  「内申30で行ける私立」には、探せないと伝える本文だけを渡す
- 偏差値の範囲で引くときは、男女のどちらかの表で帯に入れば出す（行には両方の値が書かれる）
- `access_stations` は、私立の行だけ単位なし（`矢部(617)`）で入っている。どちらもメートルとして読む
- `targetSchools.ts` の `toAdmissionRule` / `latestRulesBySchool` は `src/lib/interview/admissionRuleRow.ts` に移した
  （targetSchools.ts はブラウザ用クライアントを import 時に作るので、サーバーのルートから読めない）。
  targetSchools.ts からは再輸出している

## 答えさせ方

`renderSchools` が**県ごとに語を変える**。DBの `total_score` 列は東京と神奈川で意味が違うので、
同じ語で書かせない。

```
- 東京都 公立 日比谷［旧1学区］総合得点 920/1000・換算内申 61/65・偏差値 69 ／ 自校作成・比率7:3 ／ 出典: Vもぎ 2026年6月暫定版
- 神奈川県 公立 横浜翠嵐［横浜東部・北部・川崎地区］基準S1値 928/1000・基準内申 124/135・偏差値 72 ／ 出典: 合格基準一覧表 2026年度（紙と未突合）
- 東京都 私立 淑徳巣鴨（特進）［豊島区］ 偏差値 57 ／ 共学 ／ 出典: Vもぎ 私立 令和9年度受験用 6月時点暫定版（紙と未突合）
  - A推薦: 内申 5科19 ／ 条件 9科に1は不可 ／ 加点 英・漢・数検準2級（各）+1、…（上限+3） ／ ほかに確認 推薦基礎力検査…
  - 併願（公私）: 内申 5科22 ／ 条件 9科に1は不可 ／ 加点 …
  - 基準の出典: 私立 推薦・一般入試の基準表（冊子の年度は未確認）（紙と未突合）
```

行の頭に設置区分（公立・私立・国立）を必ず書く。同じ名前の公立と私立がありうるため。
私立・国立の行が混ざったときだけ、見出しに私立の読み方の注意（偏差値は模試会社の数字・男女別・
素内申・書かれていない条件を足さない・判定しない）を足す。

プロンプトの縛り（`answerSystem`）:

- 渡した行の数字は**そのまま読んでよい**。ただし足し算・引き算・換算をしない
- 渡していない学校は「**高校マスタに入っていません**」と答える。一般知識で補わない
- **出典をそのまま添える。「（紙と未突合）」があれば必ず伝える**
- 都県をまたいで比べない。満点の違う内申を並べない
- **合否の見込みは言わない**（「受かる／受からない」は人が決めること）
- 【探した条件】があれば、その条件の一覧として並べてよい。渡した行以外を足さない。
  「先頭の◯行だけ」「帯に入る学校は無い」も伝える
- 駅からの距離は直線距離として伝え、通学経路は学校の案内で確かめるよう添える
- 学校名の前に設置区分を添える。同じ名前の公立と私立が渡されたら両方を区分つきで示す
- 私立・国立の偏差値は出典の模試会社の数字として伝え、公立と並べて比べない。男女別は両方を伝える
- 推薦・併願優遇の基準は渡した文のまま。「条件」「ほかに確認」は省かず、書かれていない条件
  （公立との併願が必要か・併願できる校数・合格の確約）は足さない。生徒が届くかは判定しない

## 個人情報

★**この追加でも「AIヘルプは個人情報を送らない」は変わらない。**
高校マスタは全教室共通の参照データで、生徒に結びついていない。
渡すのは FAQ本文・用語集・学校の公開情報・質問・ロール・いまのパスだけ。

一方、めやすの数値は**進学研究会Vもぎ／新教育研究協会の資料**から起こしたもの。
教室内で面談の参考値として使う前提で、保護者ポータルには出していない。
AIヘルプもログインした講師・教室長しか使えないが、**外部APIに送っている**点は
[data/README.md](data/README.md) の利用条件と合わせて見ること。

## 運用

- **マスタは10分キャッシュ**している（年に数回しか変わらないため）。
  取り込み直した直後に古い数字が出たら、10分待つかデプロイし直す
- ★**PostgREST の1000行上限に当たらないようページングして読む（`.order('id')` を付けて）。**
