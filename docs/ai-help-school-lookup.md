# AIヘルプで学校名を答える（高校マスタの引き当て）

AIヘルプ（`/api/ai/help`）が、FAQ本文に加えて**高校マスタ**を材料に使う仕組み。
「日比谷の偏差値は？」「内申100くらいの神奈川の高校は？」に答えるためのもの。

正典の親: [ai-help-plan.md](ai-help-plan.md) ／ データの出どころ: [data/README.md](data/README.md)

---

## なぜFAQ本文に書かなかったか

学校ごとの数字（404校×学科）を `faqData.ts` に書く案を捨てた。理由は3つ。

1. **見出しカタログが膨らむ。** 1回目の呼び出しは全項目の見出しを毎回渡している。
   そこに400校ぶんの行が増えると、キャッシュしている塊が別物になる。
2. **数字がソースコードに凍る。** めやすは毎年変わる。差し替えのたびにPRになり、
   本番に出すまで古い数字が答え続ける。
3. **版管理が二重になる。** `high_school_standards` は `source_year` で版を積み、
   `verified_at` で「人間が紙を見たか」を持っている。FAQに書き写すと、この2つが死ぬ。

マスタは既に版と出典を持っている。そこを読むほうが正しい。

## 作り

材料が2つあり、**選び方が違う**。

| 材料       | 選び方                                  | どこ                         |
| ---------- | --------------------------------------- | ---------------------------- |
| FAQ本文    | 2段階。見出しの一覧をAIに見せて選ばせる | `src/lib/help/faqIndex.ts`   |
| 高校マスタ | **質問文から直接引く。AIに選ばせない**  | `src/lib/ai/schoolLookup.ts` |

学校をAIに選ばせないのは、選ばせる必要が無いから。学校名は質問文にそのまま出るので、
文字列で当たる。1回分の呼び出しを節約できるうえ、AIが存在しない学校を選ぶ余地も無くなる。

```
質問
 ├─ 1回目（AI）: FAQの見出し一覧 → 最大3項目
 ├─ 引き当て（コード）: 質問文 → 高校マスタの行（最大24行）
 └─ 2回目（AI）: FAQ本文 ＋ 用語集 ＋【学校のめやす】 → 答え
```

★**FAQが0件でも、学校が当たっていれば回答へ進む。**
「日比谷の偏差値は？」に当たるFAQ項目は無いため、ここを直さないと黙ってしまう。

- `src/lib/ai/schoolLookup.ts` … 純関数（引き当てと本文の組み立て）。テストはここを直接触る
- `src/lib/ai/schoolMaster.ts` … server-only。DBを読んでキャッシュする
- `src/lib/help/aiHelpPrompts.ts` … 「渡した行の数字だけを読む」の縛り

## 引き当ての決まり

### 学校名

質問文に学校名が**部分文字列として出るか**で当てる（日本語は分かち書きしないので、
`keywordSearch` の2段目と同じ考え方）。

- **長い名前を先に当てる。** 「市立横浜総合」に当たったら「横浜」では拾わない
- **`市立`／`県立`／`都立` を外した別名でも当てる。** 「横浜サイエンスフロンティア」で
  `市立横浜サイエンスフロンティア` に当たる
- ★**1文字の学校名は文脈を要求する。** 西・東・菅・旭・橘 は実在するが、
  そのまま当てると「**東**京の私立は」「関**西**の…」で誤爆する。
  `◯◯高` `都立◯◯` `県立◯◯` `市立◯◯` の形のときだけ当てる
- ★**2文字の学校名には文脈を求めない。** 戸山・湘南・三田・上野・北園・鎌倉・上溝など、
  いちばん聞かれる学校の多くが2文字で、「戸山の偏差値」と書くのが普通だから。
  最初は2文字にも文脈を求めていて、テストで「上溝の内申」が当たらないことに気づいた。
  地名と同じ名前（厚木・鎌倉など）に当たっても、渡るのはその学校の行だけで、
  答えるかどうかはプロンプト側が質問に照らして決めるので害は小さい
- **例外は「国立」。** 「国立大学」の国立に当てないよう、直後に「大」が続くときは外す

### 範囲

「偏差値55」「内申100」を正規表現で拾い、**±2**の帯で引く。

★**満点の違う内申を混ぜない。** 質問の数字が65以下なら65/75/52点満点の行（東京）、
66以上なら135点満点の行（神奈川）だけを見る。
「内申55」で神奈川の55（135点満点＝かなり低い）を混ぜると事故る。

### 県の絞り込み

質問に `都立` `東京` があれば東京都、`神奈川` `県立` `横浜` `川崎` などがあれば神奈川県。
両方・どちらも無ければ絞らない（両県を並べて出す）。

## 答えさせ方

`renderSchools` が**県ごとに語を変える**。DBの `total_score` 列は東京と神奈川で意味が違うので、
同じ語で書かせない。

```
- 東京都 日比谷［旧1学区］総合得点 920/1000・換算内申 61/65・偏差値 69 ／ 自校作成・比率7:3 ／ 出典: Vもぎ 2026年6月暫定版
- 神奈川県 横浜翠嵐［横浜東部・北部・川崎地区］基準S1値 928/1000・基準内申 124/135・偏差値 72 ／ 出典: 合格基準一覧表 2026年度（紙と未突合）
```

プロンプトの縛り（`answerSystem`）:

- 渡した行の数字は**そのまま読んでよい**。ただし足し算・引き算・換算をしない
- 渡していない学校は「**高校マスタに入っていません**」と答える。一般知識で補わない
- **出典をそのまま添える。「（紙と未突合）」があれば必ず伝える**
- 都県をまたいで比べない。満点の違う内申を並べない
- **合否の見込みは言わない**（「受かる／受からない」は人が決めること）

## 個人情報

★**この追加でも「AIヘルプは個人情報を送らない」は変わらない。**
高校マスタは全教室共通の参照データで、生徒に結びついていない。
渡すのは FAQ本文・用語集・学校の公開情報・質問・ロール・いまのパスだけ。

一方、めやすの数値は**進学研究会Vもぎ／新教育研究協会の資料**から起こしたもの。
教室内で面談の参考値として使う前提で、保護者ポータルには出していない。
AIヘルプもログインした講師・教室長しか使えないが、**外部APIに送っている**点は
[data/README.md](data/README.md) の利用条件と合わせて見ること。

## 運用

- **マスタは10分キャッシュ**している（年に数回しか変わらないため）。
  取り込み直した直後に古い数字が出たら、10分待つかデプロイし直す
- ★**PostgREST の1000行上限に当たらないようページングして読む。**
  いまは 404校 / 609行だが、めやすは毎年1版ずつ積むので数年で超える
- マスタが落ちても**ヘルプ全体は動かす**（引き当てだけ諦めてFAQで答える）
- 取り込みは `scripts/import-high-schools.mjs`（東京）と
  `scripts/import-kanagawa-schools.mjs`（神奈川）
