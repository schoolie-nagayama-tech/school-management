# 高校の学校ごとの調査の手引き（調査エージェント向け）

作成: 2026-09-23
正典: [high-school-profile-plan.md](./high-school-profile-plan.md)（なぜこの項目か・部活の4段階・出典の決まり）
対象: [data/profile-targets.csv](./data/profile-targets.csv)（通塾圏の90校）
出力: `docs/data/profiles/<tokyo|kanagawa>/<学校名>.json`（1校1ファイル）
取込: `node scripts/import-high-school-profiles.mjs --file <パス>`（`--go` なしは下見。形の検査もここで行う）

この手引きは、1校を調べるエージェントがそのまま従えるように書いてある。
**全校分がまとまった資料（生徒数・一般入試の倍率・Premiere Club）は取込済み。学校ごとの調査では集めない。**

---

## 1. 守ること

1. **値を取ってよいのは公式の資料だけ。** 学校の公式サイト、都教委・県教委、高体連・高野連・高文連・各競技の公的団体。
   **野球の試合結果に限り、一球速報.com（baseball.omyutech.com）も使ってよい。**
   みんなの高校情報などの民間まとめサイトからは値を取らない（古い・利用規約）。公式ページを探す手がかりにだけ使う。
2. **どの値にも出典URLと資料の時点を付ける。** 取れなかったら書かない（推測で埋めない）。`unresolved` に探した場所を書く。
3. **生徒の個人名を書かない。** 大会結果の資料には個人名が載っている。学校名と結果だけを書く。
4. **長い文を転載しない。** 校則・制服は自分の言葉で要約する（1項目100字まで）。
5. **食い違いは両方書く。** どちらかに寄せない。`conflicts` に、何と何が、どの資料で食い違ったかを書く。

## 2. 技術的な罠

- 学校サイトのPDFは、文字層が壊れていて `pdftotext` では読めないことが多い。
  ダウンロードして Read ツールで**画像として読む**。
- 日本語ファイル名のURLは、Node の fetch と encodeURI で取る。curl だと化ける。
  `node -e "fetch('https://…'+encodeURI('/…/令和7年度….pdf')).then(async r=>{require('fs').writeFileSync('x.pdf',Buffer.from(await r.arrayBuffer()));console.log(r.status)})"`
  リンクを拾うときは `curl -sSL <ページ> | grep -o 'href="[^"]*"'` を使う。
  全角空白が入ったファイル名もある（松が谷のパンフ `R9　松が谷高校　学校案内_1_1.pdf`）。
- **WebFetch の要約は数を間違える。** 一覧や数は原文から自分で数え直す。
- 合格実績は**延べ人数**のことが多い。表の見出しに誤植があることもある（R5の列が「R6」）。
- 学校サイトの本文は古いことがある（「普通科6クラス」と書いてあっても実際は6/7/7）。数字は統計の資料を優先する。
- 学校の経営計画の「R6実績」は、入試年度と1年ずれることがある。**年度は §4 の決まりで揃え直す。**
- 回戦の呼び方が資料で違う（学校の「1回戦」が一球速報では「2回戦」）。結果は「初戦敗退」「2勝して3回戦敗退」「ベスト16」のように書く。

## 3. どこを見るか（都立）

学校サイトは `https://www.metro.ed.jp/<略称>-h/`。「だから都立高」（`https://www.toritsuko.metro.tokyo.lg.jp/school/<略称>/`）も公式。

| 見る所                                                            | 取れるもの                                                                            |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 学校運営方針 → **学校経営報告（前年度）・学校経営計画（今年度）** | 推薦の倍率、部活加入率・全国大会、GMARCH等の現役合格数、進路決定率、満足度。★一番濃い |
| 学校運営方針 → 学校評価アンケート報告                             | 満足度（生徒・保護者）                                                                |
| 進路 → 合格実績PDF                                                | 大学別の合格者数                                                                      |
| 学校案内パンフレット                                              | 男女の人数（載せている学校だけ）、主な指定校推薦、制服、部活の実績                    |
| 部活動ページ・**部ごとのブログ**（`/activities/…`）               | 部の一覧、活動日、大会結果                                                            |
| 制服・校章・校歌、生徒心得                                        | 制服、校則                                                                            |
| お知らせ                                                          | 改築・制服変更などの変化                                                              |

## 4. どこを見るか（神奈川）

学校サイトは `https://www.pen-kanagawa.ed.jp/<略称>-h/`。

- 学校評価報告書は県の様式が**文章だけで、満足度の数値が無い**。満足度は空でよい。
- 進学実績を「実際に進学した人数＋入試方式別の割合」で出す学校がある（希望ケ丘）。**延べと混ぜない**（`basis` で分ける）。
- 制服が無い学校がある（希望ケ丘）。「制服なし」と書く。
- 校則がほぼ無い学校がある。**「規定なし」も校則の要約として書く。**
- 県の「学力向上進学重点校・エントリー校」の指定は `designation` に入れる。
- 部活の強化指定（東京の Premiere Club）に当たる制度は無い。強さは大会結果だけで判定する。
- 野球の県大会は「予選」と「本大会」がある。本大会の結果で判定する。

## 5. 集める項目

### 5-1. `stats`（数字・文字の事実）

| metric                  | item                                                                                                   | basis                                       | fiscal_year の意味              | 値                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------- | ------------------------------- | ------------------------------------------------------------------------ |

| `students`              | 空。`sex` に `male` / `female`                                                                         | 空                                          | 資料の年度                      | `value_num`。★男女の人数を公式に出している学校だけ（東京）               |
| `uniform`               | 空                                                                                                     | 空                                          | 資料の年度                      | `value_text`。形・スラックスとスカートの選択・夏服。無ければ「制服なし」 |
| `rules_summary`         | 空                                                                                                     | 空                                          | 資料の年度                      | `value_text`。頭髪・スマホ・アルバイト。規定が無いものは「規定なし」     |

- 大学群の中身：早慶上理＝早稲田・慶應・上智・東京理科。GMARCH＝学習院・明治・青山学院・立教・中央・法政。
  成成明武＝成蹊・成城・明治学院・武蔵。日東駒専＝日本・東洋・駒澤・専修。
- **学校が自分で数えた塊の数（経営報告の「GMARCH現役21名」など）があれば、それを使う。**
  無ければ大学別の表から合算し、note に「大学別の表から合算」と書く。
  両方あって合わないときは学校の数を使い、合算の数と食い違いを `conflicts` に書く。
- 合格実績は直近の1年度だけでよい。

### 5-2. `clubs`（部活。全部の部・同好会）

| キー                   | 中身                                                                                                                                            |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`                 | 学校での呼び名（原文。「男子バスケットボール部」）                                                                                              |
| `kind`                 | `運動` / `文化` / `同好会`                                                                                                                      |
| `days_note`            | 活動日の原文（「月・水・木・金・土・(日)」）。書かれていなければ省く                                                                            |
| `days_per_week`        | 週の日数。★括弧付きの曜日（「(日)」＝ときどき）は0.5日と数える。書かれていなければ省く                                                          |
| `weekend`              | `土日` / `土` / `日` / `なし` / `試合のみ`                                                                                                      |
| `tier` / `tier_basis`  | 強さの段階と根拠（§6）。根拠が無ければ両方省く                                                                                                  |
| `source_url` / `as_of` | 部活動ページのURLと時点                                                                                                                         |
| `results`              | 直近2〜3年の大会結果。`fiscal_year` `competition` `level`（`全国` `関東` `都県` `地区` `その他`）`result` `happened_on`（分かれば）`source_url` |

- 男子・女子で別の部は別の行にする。「男女硬式テニス部」は1行。
- 部の一覧は原文から数え直す。

## 6. 部活の強さ（4段階）

| 段階 | 意味               | 判定の目安                                                                                                   |
| ---- | ------------------ | ------------------------------------------------------------------------------------------------------------ |
| 1    | 私立と戦える       | 直近3年で、全国・関東大会に出場、または都県大会ベスト8以上が**2回以上**                                      |
| 2    | 都立（県立）の強豪 | Premiere Club の指定、または都県大会でベスト8が1回・ベスト16〜32が複数回、またはその年の都立（県立）で最上位 |
| 3    | 普通に活動         | 大会に出ている（上に届かない）                                                                               |
| 4    | ゆるめ             | 週3日以下で、目立つ大会実績がない                                                                            |

- `tier_basis` には、判定に使った成績を「2025年秋 都大会ベスト8（一球速報）」のように年度・大会・結果・出典で書く。
- **硬式野球部は必ず一球速報で直近3年の夏・秋・春を確認する**（学校の検索は `https://baseball.omyutech.com/` から）。
- 大会に出ているか分からず、活動日も書かれていない部は段階を付けない。

★試し調査（5校）で段階の付け方がぶれた。次の決まりで揃える。

- **「直近3年」は、2026年度の調査では2023年度以降（2023・2024・2025年度と今年度）。** 2022年度以前の成績は根拠にしない（古い全国出場で段階を付ける誤りが多かった）。
- **年度の分からない成績は根拠にしない。**「過去に関東大会出場」「昨年度」だけで年が特定できない実績は使わない。
- **1回だけの成績で段階1にしない。** 段階1は「2回以上」。全国・関東大会出場が1回、または都県の最上位賞が1回なら段階2。
- **都立・公立だけの大会（都立大会・国公立大会・公立大会）の成績は1段低く読む。** ベスト8以上で段階2、それ未満は段階3。
  段階1は、私立も出る大会の成績でしか付けない。
- **文化部**：公的な主催（高文連・各連盟）のコンクールで、都県の代表選出・金賞・最上位の賞 → 段階2。全国大会出場が2回以上 → 段階1。
  **関東大会（吹奏楽の東関東・西関東大会など）の出場は、運動部と同じく数える**（関東・全国が合わせて2回以上 → 段階1）。
  地区大会の賞・奨励賞・佳作 → 段階3。
  流派・民間主催の大会（いけばなの流派の大会、民間の軽音コンテスト）は根拠に書いてよいが、主催を明記し、全国決勝が2回以上でなければ段階2まで。
- **目標として書かれていること（「関東大会出場を目指す」）は実績ではない。**
- **段階4は「活動日が週3日以下と分かっていて、かつ実績が無い」ときだけ。** 活動日が分からない部に4を付けない（段階なしにする）。
- **活動の表彰（「かながわ部活アクティブ賞」など）は大会の成績ではない。** 段階の根拠にしない。
- **予選の無い、申し込めば出られる大会（剣道の玉竜旗など）は、出場しただけでは根拠にしない。** 勝ち進んだ結果（ベスト8など）なら根拠にしてよい。
- 同じ部の男女で成績が違うときは、男女別の行に分ける。分けられない（1つの部）なら、強い方で判定し、根拠に男女を書く。

### サッカー部はリーグの所属で判定する（2026-09-24 決定）

高校のサッカー部はほぼ全部が毎年リーグに入っていて、所属は協会が公式に出している。大会の組み合わせを追うより確かなので、
**男子のサッカー部は高円宮杯 U-18 リーグの所属（今年度）で段階を付ける。**

| リーグ                                                                 | 段階                        |
| ---------------------------------------------------------------------- | --------------------------- |
| 東京 T1・T2／神奈川 K1・K2（とその上のプリンスリーグ・プレミアリーグ） | 1                           |
| 東京 T3・T4／神奈川 K3・K4                                             | 2                           |
| 東京 T5・支部リーグ（T1〜T5にいない）／神奈川 K5・K6                   | 3（活動日が週3日以下なら4） |

- 東京：`https://www.tleague-u18.com/team.php?dy=2026&dt=1`〜`dt=5`（T1〜T5の参加チーム）。学校名は「都立◯◯高等学校」「◯◯高等学校」の形。
  **T1〜T5のどこにもいなければ支部リーグ＝段階3**。
- 神奈川：`https://www.kanagawa-fa.gr.jp/cms/u18-league/2026/div1/`〜`div6/`（K1〜K6。K3以下は組に分かれている）。
- B・Cチームは数えない。**Aチームの所属**で判定する。合同チームは合同チームの所属で判定し、根拠に「合同」と書く。
- `tier_basis` には「2026年度 高円宮杯U-18東京 T3所属」のように書く。Premiere Club の指定があれば段階2以上。
- **女子サッカーは別のリーグ**（東京都女子サッカー高校リーグ1〜3部など）。男女は必ず別の行にし、女子は大会・女子リーグの成績でふつうの決まりどおり判定する。

## 6-2. 間違えやすい数え方

- **指定校推薦の一覧と、合格した大学の一覧を混ぜない。** パンフには「一般選抜・総合型選抜・学校推薦選抜（公募）による合格大学」のような
  合格大学の一覧が、指定校の一覧のすぐ隣に載っていることがある（日野で取り違えた）。指定校は「指定校」と見出しにある一覧だけ。
- **延べ・現役・実進学が資料に書かれていない数は、推測で `basis` を付けない。** 入れずに `unresolved` に書く。
- 学校独自の大学群（「成成獨國武明学」など）は、`item` にその名前をそのまま使ってよい。手引きの群に組み直さない。

## 7. `designated_universities`（指定校推薦）

学校が**公式に**大学名を出しているときだけ（パンフの「主な指定校推薦」など）。
`university`・`fiscal_year`（年度が書かれていなければ null）・`source_url`・`note`。

## 8. `events`（学校の変化）

2020年以降と、予定が出ているもの。

| キー           | 中身                                                                     |
| -------------- | ------------------------------------------------------------------------ |
| `kind`         | `改築` `改修` `制服` `学級増減` `学科改編` `統合` `指定` `施設` `その他` |
| `period_label` | 「2023年8月」「2025年度から」など（必須）                                |
| `happened_on`  | 日付が分かるときだけ                                                     |
| `summary`      | 何が起きたか（1文）                                                      |
| `source_url`   | 出典                                                                     |

学級の増減は、都教委の「第一学年生徒の募集人員等について」（毎年10月の発表）で確かめられる。
