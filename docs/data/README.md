## toritsu-goukaku-meyasu-2027.csv

出典: 進学研究会「Vもぎ」令和9（2027）年度受験用 都立高校 総合得点 合格めやす表〔暫定版 6月時点〕（2026年6月）
起こし: 2026-09-22・写真4枚から。AI 2人（opus / sonnet）が独立に読み取り、205行×全項目で完全一致。
　　　　加えて Fable が写真から19件を抜き取りで当てて不一致ゼロ。
件数: 205行。**学校・学科の構成と行順は令和8年度版と同一**（増減なし）。列の定義は2026年版と同じ。

★**暫定版。** 紙の頭書きに「データ解析中のため、今後基準値を変更する場合があります。最新の基準値は
8・9月以降進研Vもぎで確認して下さい」とある。**9月版が出たら 2028 ではなく同じ年度の確定版として
差し替える**（ファイル名は `-2027.csv` のまま、この節の出典と起こし日を更新する）。

前年との差: **内申・偏差値は205行すべて前年と同じ。動いたのは総合得点だけ**で、
−5が28校・変化なし79校・+5が57校・+10が41校。読み違いなら内申や偏差値にもばらつきが出るので、
この分布自体が読み取りの傍証になっている。

紙にだけある注記: **深沢は「R8年度より単位制に改編（7:3での選抜のめやす）」**（`note` に入れた）。

**2026-09-22 に人間が紙と突き合わせて「間違いなし」を確認**（目視チェック用の Excel で205行）。
同日、`high_school_standards` に `source_year=2027`・`source_label='Vもぎ 2026年6月暫定版'`・
`verified_at` ありで205行を積んだ（2026年版の205行はそのまま。合計410行）。

取込コマンド:


## toritsu-school-station-r7.csv

**加工データ。** 次の2つを突き合わせて、こちらで算出した。

- 学校の座標: `toritsu-school-address-r7.csv` の住所を
  国土地理院 ジオコーディングAPI（https://msearch.gsi.go.jp/address-search/AddressSearch）で変換
- 駅の位置・路線: 国土交通省 国土数値情報「鉄道データ N02-25（2025年版）」
  https://nlftp.mlit.go.jp/ksj/gml/data/N02/N02-25/N02-25_GML.zip
  （利用は国土数値情報の利用約款に従う。出典明記で利用可）

作成: 2026-09-21 ／ 187行（算出169・手動11・鉄道なし5・座標なし2）

| 列                                         | 中身                                                                |
| ------------------------------------------ | ------------------------------------------------------------------- |
| `school_code` `school_name` `municipality` | 所在地CSVから                                                       |
| `lat` `lon`                                | 学校の緯度経度（世界測地系）                                        |
| `primary_station`                          | 主たる最寄駅                                                        |
| `primary_distance_m`                       | そこまでの直線距離（m）                                             |
| `primary_lines`                            | 主たる最寄駅に乗り入れる**全路線**。`運営会社 路線名` を `;` 区切り |
| `source`                                   | `算出`／`手動`（上書き）／`鉄道なし`（離島）／`座標なし`            |
| `access_stations`                          | その学校に通える駅と距離。`駅名(距離m)` を `;` 区切り               |
| `access_lines`                             | 通える駅の全路線。**沿線での絞り込みはこの列を使う**                |

`access_stations` の中身は `source` で意味が変わる。

- `算出` … 直線2km以内の駅（＝歩ける範囲、という前提）
- `手動` … **学校公式サイトが案内している駅そのもの**。距離は問わない

バス通学の学校は2km圏に駅が無く、算出のままだと沿線が空になる（調布北は0駅）。
公式の案内で埋めることで、沿線が空の学校は0校になった。

### ★乗換駅は2段階でまとめている

1つの駅に複数の路線が乗り入れるとき、路線ごとにバラバラの駅として扱うと沿線が片方しか出ない。
そこで2段階でまとめた。

1. **国土数値情報の駅グループコード。** 同じ会社の複数路線と、同名の他社をまとめる。
   例: 立川＝JR中央線・青梅線・南武線／町田＝小田急小田原線・JR横浜線。
2. **会社名の冠を外して同名かつ600m以内なら同一駅とみなす。**
   会社ごとに駅名が違う乗換駅は1.では別々に残るため。
   例: **京王永山（40m）小田急永山 → 永山**／京王・小田急・モノレールの多摩センター／
   京王八王子とJR八王子（446m）。

この2段目で26組が統合され、駅は1578→1552になった。
統合された組はすべて実在の乗換駅であることを目視で確認している。

結果、**主たる最寄駅が複数路線の学校は37校**。永山高校は `京王電鉄 相模原線;小田急電鉄 多摩線` の2路線を持つ。

★**冠を外した名前を使うのは、実際に統合したときだけ。** 単独の駅に使うと「西武立川」が
「立川」に化けてJR立川と区別できなくなる（一度そのバグを出した）。
いま武蔵村山高校の `access_stations` には `西武立川(3474m)`、拝島高校には `立川(6218m)`（JR）が
正しく別々に入っている。

### ★距離は直線距離。徒歩の距離ではない

山や川で隔てられていると、直線では近くても歩けない。
**この表の最寄駅を、学校案内の「最寄駅」として保護者に見せてはいけない。**
使ってよいのは「沿線で候補を絞る」ところまで。最寄駅そのものを伝えるなら学校のサイトを見る。

### school-station-overrides.csv（手で上書きする）

直線距離が実態と合わない学校を、手で直すためのファイル。`school_code` で効く。
`stations` は `;` 区切りで複数書ける。**先頭が主たる最寄駅**になり、
書いた駅ぜんぶが `access_stations` になる。`source` 列が `手動` になるので、
どれを人が決めたか後から分かる。理由も1校ずつ書いてある。

久留米西は東久留米市にありながら清瀬駅が算出されたため疑ったが、
公式サイト自身が清瀬駅を筆頭に案内していた。算出は正しかった。

なお、スクリプトが出す「算出のまま1.2km超」の9校は**この確認済みの9校**であって、
未確認という意味ではない。

### 離島7校

大島・新島・神津・大島海洋国際・小笠原は鉄道が無いので `source=鉄道なし`。
★当初は「最寄駅が5km超なら鉄道なし」としていたが、これだと野津田高校（町田駅まで5343m・
バス通学）まで巻き込んで壊れた。**距離ではなく学校番号で明示的に除いている。**
三宅・八丈はジオコーディングが当たらず `座標なし`。いずれも合格めやす表には載っていない。

## 全体の作り

```
toritsu-goukaku-meyasu-2026.csv   写真から手起こし  学校×学科 → 得点・内申・偏差値
        │ school_name で結合（161/162 一致）
toritsu-school-address-r7.csv     都教委 CC BY      学校 → 市区町村・住所
        │ school_code で結合
toritsu-school-station-r7.csv     こちらで算出      学校 → 座標・最寄駅・沿線
        ↑ school-station-overrides.csv  手動の上書き(現在11校12行)
```

おすすめ学校を出すときは、この3つを結合した1つのマスタにする。
**数値の出どころが3種類（手起こし／公式／算出）あるので、マスタにも出どころの列を残す。**
手起こしの数値だけは紙との突き合わせが済んでいない。
