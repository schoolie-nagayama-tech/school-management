## ★神奈川: kanagawa-goukaku-kijun-2026.csv

出典: 新教育研究協会 2026年度 神奈川県公立高校 合格基準一覧表 ＜普通科・単位制普通科＞＜専門学科・総合学科・昼間定時制＞
起こし: 2026-09-22・写真2枚（2000×2000）から。AI 2人（opus / sonnet）が独立に読み取り、199行×全項目で一致
（割れたのは右端で切れた内申4行だけで、決まりどおり空欄に統一）。Opus が写真から16件を抜き取りで当てて不一致ゼロ。
件数: 199行（普通科・単位制普通科110［5地区: 30/24/18/14/24］／農業・水産18／工業・総合産業29／商業8／総合学科10／その他24）

★**東京と列の意味が違う。** 同じ `high_school_standards` に入れているが、混ぜて読まないこと。

| CSVの列               | DBの列                        | 神奈川での意味                                                                 |
| --------------------- | ----------------------------- | ------------------------------------------------------------------------------ |
| `s1`                  | `total_score`                 | **基準S1値**。1000点満点・各校の内申と学力検査の比率で計算・特色検査を含まない |
| `naishin`             | `naishin` / `naishin_max`     | **基準内申**。重点化校も含めて全て**135点満点**（中2の9教科＋中3の9教科×2）    |
| `hensachi`            | `hensachi`                    | 基準偏差値                                                                     |
| `region`              | `high_schools.region`（新設） | 資料上の地区（5つ）。★学区ではない（神奈川に学区制は無い）                     |
| `tanisei`・`subjects` | `note` に文字で               | 単位制・3教科入試・4教科入試                                                   |

- 東京の `total_score`（総合得点＝学力検査＋調査書）と神奈川の `total_score`（基準S1値）は、
  **同じ1000点満点でも算出法が違う。県をまたいで比べない。**

- 所在地・最寄駅はこの資料に無い。県のオープンデータから別に起こした（§神奈川の所在地と最寄駅）

★**内申が空の16校**（2枚目の右端「厚木海老名愛甲・大和座間綾瀬・相模原地区」が写真の縁で切れていた）:
厚木王子・上溝南・上溝・橋本・厚木西・有馬・綾瀬・相模田名・厚木北・相模原城山・大和南・上鶴間・厚木清南・綾瀬西・津久井・愛川。

★**暫定版。** 紙の頭書きに「データ解析中のため、今後基準値を変更する場合があります。最新の基準値は
8・9月以降進研Vもぎで確認して下さい」とある。**9月版が出たら 2028 ではなく同じ年度の確定版として

**2026-09-22 に人間が紙と突き合わせて「間違いなし」を確認**（目視チェック用の Excel で205行）。
同日、`high_school_standards` に `source_year=2027`・`source_label='Vもぎ 2026年6月暫定版'`・

取込コマンド:

## toritsu-school-station-r7.csv

**加工データ。** 次の2つを突き合わせて、こちらで算出した。

- 学校の座標: `toritsu-school-address-r7.csv` の住所を
  国土地理院 ジオコーディングAPI（https://msearch.gsi.go.jp/address-search/AddressSearch）で変換
- 駅の位置・路線: 国土交通省 国土数値情報「鉄道データ N02-25（2025年版）」
  https://nlftp.mlit.go.jp/ksj/gml/data/N02/N02-25/N02-25_GML.zip
  （利用は国土数値情報の利用約款に従う。出典明記で利用可）

作成: 2026-09-21 ／ 187行（算出169・手動11・鉄道なし5・座標なし2）

| 列                                         | 中身                                                                |
| ------------------------------------------ | ------------------------------------------------------------------- |
| `school_code` `school_name` `municipality` | 所在地CSVから                                                       |
| `lat` `lon`                                | 学校の緯度経度（世界測地系）                                        |
| `primary_station`                          | 主たる最寄駅                                                        |
| `primary_distance_m`                       | そこまでの直線距離（m）                                             |
| `primary_lines`                            | 主たる最寄駅に乗り入れる**全路線**。`運営会社 路線名` を `;` 区切り |
| `source`                                   | `算出`／`手動`（上書き）／`鉄道なし`（離島）／`座標なし`            |
| `access_stations`                          | その学校に通える駅と距離。`駅名(距離m)` を `;` 区切り               |
| `access_lines`                             | 通える駅の全路線。**沿線での絞り込みはこの列を使う**                |

`access_stations` の中身は `source` で意味が変わる。

- `算出` … 直線2km以内の駅（＝歩ける範囲、という前提）
- `手動` … **学校公式サイトが案内している駅そのもの**。距離は問わない

バス通学の学校は2km圏に駅が無く、算出のままだと沿線が空になる（調布北は0駅）。
公式の案内で埋めることで、沿線が空の学校は0校になった。

### ★乗換駅は2段階でまとめている

1つの駅に複数の路線が乗り入れるとき、路線ごとにバラバラの駅として扱うと沿線が片方しか出ない。
そこで2段階でまとめた。

1. **国土数値情報の駅グループコード。** 同じ会社の複数路線と、同名の他社をまとめる。
   例: 立川＝JR中央線・青梅線・南武線／町田＝小田急小田原線・JR横浜線。
2. **会社名の冠を外して同名かつ600m以内なら同一駅とみなす。**
   会社ごとに駅名が違う乗換駅は1.では別々に残るため。
   例: **京王永山（40m）小田急永山 → 永山**／京王・小田急・モノレールの多摩センター／
   京王八王子とJR八王子（446m）。

この2段目で26組が統合され、駅は1578→1552になった。
