# ③「時期の重要性」で話すこと（記入シート）

面談カードの③で出す定型トークを、ここに書く。書いたものを
`src/lib/interview/scenes.ts` へ写す。

**ここはAIに書かせない場所。** 毎回同じことを言うので、AIに毎回考えさせる意味がない。
書いた文がそのまま画面に出る。

空のままのマスは、面談カードで「この学年・季節の定型トークはまだ用意されていません」と出て、
定型行は出ない。**埋め草を書くより空のほうがいい**ので、無理に全部埋めなくてよい。

## ★都県で分かれている（2026-09-22 追加）

緑園都市校は神奈川県。**都立と神奈川県立は制度も日程も別物**なので、マスは
学年区分 × 季節 × 都県になった。書き写す先は2つある。

| 書き写す先 | 何を書くか |
| --- | --- |
| `COMMON_TIMING` | 都県が変わっても同じ話。学校の年間の流れ、ご家庭へのお願い |
| `REGION_TIMING` | **都県ごとの話。入試制度・日程・教科別対策はすべてこちら** |

画面に出るのは COMMON → REGION を繋げたもの。

### 教科別の話は③と⑤の両方に出す

「なぜ今この教科なのか」は、③では**なぜ今かの答え**、⑤では**なぜこのプランかの根拠**として
読む。面談は①から順に進むので、プラン表を開いた場で根拠が手元にあるほうが使える。

**同じ行を2か所に出すので、文字列の定数は1つにする**（片方だけ直すと面談の中で食い違う）。
神奈川・中3・冬期の `KANAGAWA_JUNIOR3_WINTER_SUBJECTS` がその形。
③は `REGION_TIMING` から、⑤は `REGION_PLAN_RATIONALE` から同じ定数を参照している。

- ★**同じ文を2か所に書き写さない。** 定数に切り出して両方から参照する
- ★**制度の話を COMMON に書かない。** 都立は1020点の総合得点1本・併願優遇は12月15日の
  入試相談、神奈川は打診値表と前期/後期の内申。混ぜると面談でそのまま事故る
- 教室と都県の対応は `src/lib/interview/region.ts`。**教室が増えたらここに1行足す**。
  足し忘れた教室では定型行が出ない（知らない都県に東京の話をするより安全という判断）

## 1マスに書く4つの観点

本部の「夏期保護者面談 チェックリスト」③から起こしたもの。

| # | 観点 | 何を言うか |
| --- | --- | --- |
| 1 | **目標までの期間** | 入試まで／学年末まで、あと何か月あるか。残り時間の感覚を合わせる |
| 2 | **年間計画の中のいまの位置** | 前の時期に何があったか、この時期に何をするか、次の時期に何が起きるか |
| 3 | **この季節の意味** | 他の季節と何が違うのか。なぜ「いま」なのか |
| 4 | **やること** | 家庭にて／学校にて／IEにて、それぞれ何をするか |

## 書き方

- **1行1メッセージ。** 保護者に読み上げる文ではなく、話す順の覚え書き
- 時期と中身は全角ダッシュで区切る ―― 「7〜8月 ―― 部活が終わり…」
- 3〜5行が目安。長いと面談中に読まれない
- 数字（入試まで◯日）は書かない。システムが別に出す

## 記入例（中3・夏期）

本部のチェックリストから起こしたもの。**これを型にする。**

```
年間学習計画を見ながら、いまがどの地点かを確認する
7〜8月 ―― 部活が終わり、まとまった時間が取れる最後の時期
9月以降 ―― 内申が決まる2学期。三者面談と出願までの流れ
夏と冬の違い ―― 冬は範囲を詰められない。戻れるのは夏だけ
```

観点との対応:

- 1行目 → 観点2（年間計画の中のいまの位置）
- 2行目 → 観点3（この季節の意味）
- 3行目 → 観点2（次の時期に何が起きるか）
- 4行目 → 観点3（他の季節との違い）

観点1（期間）と観点4（やること）は、この例では書かれていない。
観点1はシステムが日数で出すため、観点4は生徒ごとに違うため。
**4つ全部を埋める必要はない。** その学年・季節で効くものだけでよい。

## 書いたあと

`src/lib/interview/scenes.ts` の該当マスに、1行を1つの文字列として並べる。
**入試制度の話は `REGION_TIMING` の都県のほうへ。**

```ts
const REGION_TIMING: Record<Region, TimingGrid> = {
  tokyo: {
    junior12: {
      spring: [],
      summer: [
        '7〜8月 ―― 学校が止まるので、つまずいた単元まで戻れる',
        '2学期 ―― 内容が急に難しくなる。ここで差がつく',
      ],
      winter: [],
    },
    // …
  },
  kanagawa: { /* … */ },
};
```

書き終えたら面談カードで実際に開いて、その学年の生徒で出るか確かめる。

## 入試日について

**都立の第一次募集・分割前期の日付だけを持つ**ことにした（`src/lib/interview/examDates.ts`）。
令和9年度入試は **2027年2月21日**（推薦 1/26・27、二次 3/9）。

- ★**中3のときだけ「入試まであと◯日」を出す。** 中1・中2に「あと900日」と言っても面談で使わない
- ★**年度ごとに手で足す。** 毎年9月に都教委が実施要綱を出すので、そのとき更新する。
  年度が無ければ日数を出さない（当て推量の日付を出さない）
- ★**東京都のみ。** 緑園都市校が抱える神奈川県立は制度も日程も別物なので混ぜない。
  神奈川の教室では「入試まであと◯日」の行そのものが出ない。
  **神奈川県の共通選抜の日程を確かな出どころで持つまで、都立の日付を代わりに見せない**

## 決まっていないこと

- **季節の判定が暫定。** いま何期の面談かは月から機械的に決めている
  （3〜5月＝春期／6〜8月＝夏期／9〜2月＝冬期）。講習の期の設定を読むようにしたら差し替える。
  詳細は `src/app/interview/interview.shared.ts` の `currentSeason`
- **小学生・高校生の型。** 入試の話が中心にならないので、中学生とは別の観点が要る
- **神奈川の入試情報が vault に無い。** 神奈川県立の合格めやす（打診値表）も高校マスタに
  入っていない。中3・冬期の文中の制度の話は、いまは教室長の記述が唯一の出どころ
