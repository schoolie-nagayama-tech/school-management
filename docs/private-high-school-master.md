# 私立高校マスタと推薦・併願優遇の判定

2026-09-25 着手。面談④（志望校と提案）で、私立も都立と同じ表に並べ、推薦・併願優遇の基準に
本人の内申が届いているかをシステムが判定する。

## 方針（教室長）

- 私立も「都立に準拠」して、同じ高校マスタ・同じ表に並べる。
- **「私立の方が複雑で個別の条件がある。だからこそシステムに手伝ってほしい」**。
  当初「私立特有の基準は自由記述1本で最小限に」と提案したが、これは否定された。
  条件を式として持ち、本人の通知表に当てて「届いている／あといくつ／なぜ不可か」を出す。

## データの持ち方

| 表                                  | 私立で入るもの                                                                                                                                                |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `high_schools`                      | 学校×コースで1行（都立と同じ）。`establishment`（公立/私立/国立）・`gender_type`・`phone` を足した。一意は `(prefecture, establishment, school_name, course)` |
| `high_school_standards`             | Vもぎの私立の偏差値。男子表・女子表で別の行（`gender`）。一意は `NULLS NOT DISTINCT (high_school_id, source, source_year, gender)`                            |
| `high_school_admission_rules`（新） | 推薦・併願優遇の基準。1行＝学校×コース×入試区分×対象（都内生／都神外生…）×性別。条件は `rule` jsonb                                                           |

- 別テーブルにしなかった理由: 志望校（`student_target_schools.high_school_id`）・検索・④の表・地図が
  「学校＝`high_schools` の1行」を前提にしているため。
- 冊子の「地区」（「世田谷」「八王子」）は正式な区市名ではないので `region` に入れた（`municipality` は空）。
- **所在地（緯度経度）は無い。** ④の提案（近くの学校を挑戦・順当・安全に並べる）は距離で絞るので、
  私立は登録済みの志望校としてだけ表に並び、提案の候補にはならない（`src/lib/api/targetProposals.ts`）。

## 条件の式（`rule` jsonb）

型の正典は `src/lib/interview/privateAdmission.ts` の `AdmissionRuleBody`。

- `any`: 外側がOR（①②③のいずれか）、内側がAND（「かつ」）
- `gates`: 区分全体の前提（「9科に1は不可」「英4」）。1つでも満たさなければ不可
- `bonus`: 内申への加点（上限 `max`、合計ごとの上限 `max_by`、乗る合計 `applies_to`）。
  「英検準2級なら基準-1」のような緩和も加点として表す
- `no_criterion`: 内申の基準が無い理由（「内申基準なし（学力重視）」）

条件の種類: `sum`（合計）/ `avg`（平均）/ `each`（各教科の最低）/ `none_le`（◯以下が無い）/
`any_ge`（◯以上がある）/ `cert`（検定）/ `manual`（式にできない数値条件）。
教科の束は `3科`（国数英）`5科` `9科` `実技4科`、教科の配列、`{best, of, plus}`（「5科のうち任意の3科」）。
学年は `years`（省略＝3年次。神奈川方式は `[{grade:2,w:1},{grade:3,w:2}]`）。

## 判定の決まり

- 判定に使う内申: 中3の2学期（2期制は後期）→ 無ければ中3の1学期（「仮に判定」）→ 無ければ中2の学年末（同）。
- 状態: 届いている／加点込みで届いている（本人の評定で分かる加点。「9科に5がある」など）／条件つき（数値は届くが検定などが要る）／
  加点次第（検定などの加点で届く）／届かない／不可（前提で落ちる）／内申では決まらない／内申が未入力。
- ★検定（英検・漢検・数検）は NEST に無い。持っていると仮定して「届いている」とは言わない。
- ★欠席日数・説明会参加・作文などは判定に混ぜず「面談で確かめること」に並べる。
- ★加点は冊子の上限を超えて見込まない。同じ検定の級違い（3級と準2級）は高いほう1つだけを見込む。
- ★判読できなかった数値は、取込で `manual`（要確認）に倒す。null のまま入れると「届いている」と出る。
- 代表の区分: 併願優遇（公私）→ 併願（公）→ 推薦 → 単願。**教室の生徒が受けられない区分**
  （「都神外生」「埼玉・千葉県生」など）は使わない（`scopeApplies`）。
- 男女で偏差値が違う共学校は、差を出さず両方を並べる（NEST は生徒の性別を持っていない）。

## 画面

- 志望校欄（`TargetSchoolsPanel`）: 候補に「東京私立」のように設置区分を添える。
- ④根拠の「志望校」の行: 代表の区分の判定と理由（`privateAdmissionBlock`）。基準が未照合なら「基準は原本と未照合」。
- ④根拠の下: 学校ごとに畳んだ「推薦・併願の条件」（`PrivateAdmissionDetails`）。区分の切り替え・条件ごとの達成・加点・確認事項・原文。
- ④の話すこと: 「◯◯：併願（公私）の内申の基準は届いている」など（`privateAdmissionTalkLines`）。
- ④の表（志望校と提案）: 私立の行は「内申めやす」の欄に代表の区分の判定を出す。
- AIヘルプには私立を載せない（`src/lib/ai/schoolMaster.ts` で公立に絞っている）。プロンプトが「都立・神奈川県立」前提のため。

モック: `docs/mockups/private-school-judgment.html`

## 材料と取込

- `docs/data/private/criteria-*.json`: 冊子「推薦・一般入試の基準表」の写真をAIが書き起こしたもの（1ページ1ファイル。
  東京 p2〜14・埼玉 p22〜23・神奈川 p23〜27・茨城/栃木/国立 p27〜28）。東京 p1、千葉と埼玉の前半（p15〜21）は受け取っていない。
- `docs/data/private/hensachi-*.json`: Vもぎ「私立高校 合格のめやす」令和9年度受験用・6月時点暫定版（東京 男女・千葉埼玉神奈川 男女）。
- `docs/data/private/hensachi-aliases.json`: 偏差値表の「学校名(コース)」→ 基準表の学校・コースの対応。
  `courses` は複数可（偏差値表が複数コースを1行にまとめるため）。男女で募集が分かれる学校は `courses_by_gender`。
  決め手の無いものは `null`（取り込まない）。★推測で当てない。
- `docs/data/private/meta.json`: 出典名・年度・ラベル。**冊子の年度は表紙が無く未確認**（ラベルに明記）。
- 取込: `node scripts/import-private-high-schools.mjs`（下見）→ `--go`。同じ版の基準は消してから入れ直す。
