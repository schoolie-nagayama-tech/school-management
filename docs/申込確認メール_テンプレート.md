# 申込後送付メール テンプレート

フォーム申込完了後に申込者へ送信されるメールのテンプレートです。  
実装: `supabase/functions/send-form-notification/index.ts`

---

## 申込者向けメール（確認メール）

### 件名（Subject）

```
【${教室名}】${フォーム種別名}のお申し込みを受け付けました
```

**例:** `【〇〇教室】模試申込のお申し込みを受け付けました`

---

### 本文（HTML）

```html
<div style="font-family: sans-serif; max-width: 600px; margin: 0 auto;">
  <h2 style="color: #ff8e3c;">お申し込み受付完了</h2>
  <p>${生徒名} 様</p>
  <p>以下の内容でお申し込みを受け付けました。</p>
  <div style="background: #f5f5f5; padding: 20px; border-radius: 8px; margin: 20px 0;">
    <h3 style="margin-top: 0;">申込内容</h3>
    <p><strong>種別:</strong> ${フォーム種別名}</p>
    <p><strong>申込日時:</strong> ${申込日時（日本時間）}</p>
    <p><strong>生徒名:</strong> ${生徒名}</p>
    <p><strong>学年:</strong> ${学年ラベル（小1〜高3など）}</p>
    <hr style="border: none; border-top: 1px solid #ddd; margin: 15px 0;" />
    <h3>フォームのご記入内容</h3>
    <p>お申し込み時にご記入いただいた内容は以下のとおりです。</p>
    ${フォーム種別ごとの申込詳細（下記参照）}
  </div>
  <p>ご不明点がございましたら、教室までお問い合わせください。</p>
  <p style="margin-top: 30px; color: #666;">${教室名}</p>
</div>
```

---

### プレースホルダー一覧

| 変数                            | 説明                                   | 例                                   |
| ------------------------------- | -------------------------------------- | ------------------------------------ |
| `${教室名}`                     | 教室の名前（schools.name）             | 〇〇教室                             |
| `${フォーム種別名}`             | FORM_TYPE_LABELS[form_type]            | 模試申込、Vもぎ申込、増コマ申込 など |
| `${生徒名}`                     | 申込時の生徒名（student_name）         | 山田 太郎                            |
| `${申込日時}`                   | created_at を日本時間で表示            | 2026/2/4 14:30:00                    |
| `${学年ラベル}`                 | grade の表示用（小1〜高3、既卒）       | 中2                                  |
| `${フォーム種別ごとの申込詳細}` | response_data を種別ごとに整形したHTML | 下記「詳細ブロック」参照             |

---

### 「詳細」ブロック（フォーム種別ごと）

- **増コマ申込 (zoukoma)**  
  科目別コマ数、合計コマ、金額、希望日程、備考

- **Vもぎ申込 (mogi)**  
  選択した日程・会場、備考

- **模試申込 (moshi)**  
  選択した模試（試験名・日付・会場）、備考

- **週回数変更 (shukaisu)**  
  現在の週回数、変更後の週回数、変更理由、備考

- **曜日変更 (youbi)**  
  現在の曜日、変更後の曜日、変更理由、備考

- **教材販売 (kyozai)**  
  選択した教材（名前・価格）、合計金額、備考

- **お客様相談 (soudan)**  
  相談カテゴリ、相談内容

## 差出人と返信先

- 差出人は全教室共通の `スクールIE <noreply@school-ie.com>`。★`school-ie.com` は受信サーバー（MX）を持たないため、noreply 宛ての返信は届かず、約2日後に不達で戻る。
- そこで申込者向けメールには **返信先（Reply-To）に教室メール** を付ける。値は問合せ管理の教室別設定「返信先メールアドレス」（`inquiry_school_settings.mail_reply_to`）を共用する（追客メールと同じ窓口に返信を集めるため）。
  - 設定あり: 本文末尾に「このメールにご返信いただくと、${教室名}に届きます。」
  - 未設定: 返信先を付けず、従来どおり「送信専用です。このメールに返信いただいてもお答えできません。」
- 講師向けのシフト提出完了・シフト修正のお願いも同じ扱い。
- 教室長向けの通知メール（申込・シフト提出）は教室内の連絡なので返信先を付けず、送信専用のまま。

## 教室長向け通知メール（参考）

件名: `【新規申込】${フォーム種別名}がありました`  
本文: 申込情報（種別・日時・生徒名・学年・メールアドレス・詳細）＋「管理画面で確認」ボタンリンク
