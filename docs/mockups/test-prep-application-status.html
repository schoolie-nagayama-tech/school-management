このモックについて
  • 「テスト対策提案書」一覧に、生徒ごとに増コマ申込が済んでいるか（未申込か）を出す改修案。
  • 判定は「選んだ期（対象の期）の増コマ申込に、その生徒の回答があるか」で行う。提案書と申込を直接つなぐ列はDBに無いため、生徒と期で突き合わせる。
  • 未申込チップは公開中の提案書だけを数える（下書きは保護者にまだ見えていないため）。
  • 増コマ申込のうち生徒に紐付いていない回答は、この判定には入らない（該当生徒は未申込のまま表示される）。
  • 表の並び順は、未申込を上・提案コマの多い順、その下に申込済という順にしている（未申込を上から追えるように）。
